# DreemWorld — HTML-прототип

Интерактивный статический прототип главного экрана DreemWorld: центральное Солнце, 22 планеты интересов, поиск, анимации и открывающиеся окна со структурой тематических сообществ.

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.

Для публикации на GitHub Pages:
1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `style.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
5. После публикации откройте выданную GitHub Pages ссылку.

## Файлы
- `index.html` — структура интерфейса.
- `style.css` — визуальный стиль, адаптивная вёрстка и CSS-анимации.
- `app.js` — 22 планеты, поиск, расположение в галактике, интерактивные тематические окна.
- `README.md` — эта инструкция.

## Важно
Это фронтенд-макет: кнопки и переходы демонстрируют сценарий, но авторизация, реальные участники, чаты, новости, карта, база данных и сервер пока не подключены. Изображения планет сделаны CSS-эффектами и эмодзи, чтобы проект запускался без дополнительных файлов. Шрифт Manrope загружается из Google Fonts, но при отсутствии интернета используется системный шрифт.
