# План разработки Dreem World

## 1. Цель

Создать кроссплатформенное приложение **Dreem World** — сервис для знакомств, общения и поиска людей по всему миру по интересам, со встроенным ИИ.

Приложение работает на **Android, iOS и Web** из единой кодовой базы, данные синхронизируются между устройствами в **режиме реального времени**.

## 2. Принятые решения

| Область | Решение |
|---|---|
| Стек | **Flutter** (единая кодовая база: Android + iOS + Web) |
| Управление состоянием | **Riverpod** |
| Навигация | **go_router** |
| Бэкенд и реалтайм | **Supabase** (Postgres + Realtime + Auth + Storage) за абстракцией репозиториев |
| ИИ | Интерфейс `AiService` + **мок-реализация** (`MockAiService`); реальный провайдер подключается позже |
| Автоперевод | Интерфейс `TranslationService` + мок-реализация |
| Локальное хранилище | `shared_preferences` (настройки, сессия) + in-memory кэш |
| Дизайн | **Неоновый вайб**, 5 переключаемых тем |

## 3. Дизайн: 5 неоновых тем

Всего 5 тем, пользователь выбирает любую в настройках (сохраняется):

1. **Neon Violet** — фиолетовый + циан (по умолчанию, из концепта)
2. **Cyber Pink** — маджента + розовый
3. **Matrix Green** — зелёный + бирюзовый
4. **Neon Sunset** — оранжевый + розовый + фиолетовый
5. **Ice Blue** — голубой + синий

Общие черты: тёмный фон, неоновые акценты, свечение (glow), градиенты, скруглённые карточки, минималистичная типографика.

## 4. MVP: состав экранов

1. **Splash** — заставка + логотип
2. **Onboarding** — 3–4 слайда с идеей приложения
3. **Создание профиля** — имя, возраст, город, фото (заглушка), интересы, цели, ценности
4. **Выбор темы** — 5 неоновых вариантов
5. **Подбор (Discovery)** — карточки людей с процентом совместимости
6. **Мэтч** — экран взаимной симпатии
7. **Чаты** — список диалогов
8. **Чат** — переписка + кнопка автоперевода + подсказки тем от ИИ
9. **Настройки** — выбор темы, приватность, выход

### Слои данных

- **Репозитории** — интерфейсы (`ProfileRepository`, `MatchRepository`, `ChatRepository`).
- **Мок-реализации** — работают локально, эмулируют реалтайм через `Stream`.
- **Реалтайм-слой** — `RealtimeService` с двумя реализациями: `MockRealtimeService` (сейчас) и `SupabaseRealtimeService` (при подключении).
- **ИИ** — `AiService.computeCompatibility()`, `AiService.suggestTopics()`; сейчас `MockAiService`.

## 6. Синхронизация в реальном времени

- Все данные проходят через репозитории с потоками (`Stream`).
- Мок-режим эмулирует мгновенную синхронизацию между экранами.
- При подключении Supabase тот же интерфейс начнёт транслировать изменения между устройствами.

## 9. Ограничения текущего окружения

- **Android SDK** не установлен — сборка APK требует доустановки Android SDK/JDK.
- **iOS** собирается только на macOS (здесь невозможно).
- Проверка и сборка выполняются для **Web** (`flutter build web`) и статическим анализом.
