# Архитектура Dreem World

## Обзор

Единая кодовой база Flutter для Android, iOS и Web. Слоистая архитектура с абстракцией данных: сейчас работают мок-реализации, позже подключается Supabase без изменения UI.

## Слои

```
UI (features/*)  →  Провайдеры Riverpod  →  Репозитории (интерфейсы)  →  Источники данных
                                                                    ├── Mock (сейчас)
                                                                    └── Supabase (позже)
```

### 1. UI (features)

Экраны по фичам: `onboarding`, `profile`, `discovery`, `match`, `chat`, `settings`. Экраны не знают про источник данных — только про репозитории через провайдеры.

### 2. Состояние (Riverpod)

Провайдеры связывают UI и репозитории. Тема, сессия и данные профиля — отдельные провайдеры.

### 3. Данные (data)

- **models** — сущности: `User`, `Profile`, `Interest`, `Match`, `Message`, `Conversation`.
- **repositories** — интерфейсы и мок-реализации.
- **services** — `AiService`, `TranslationService`, `RealtimeService`.

### 4. Источники

- **Mock** — данные в памяти, потоки для эмуляции реалтайма.
- **Supabase** — Realtime-каналы, таблицы Postgres, Auth.

## Реалтайм

`RealtimeService` отдаёт `Stream` изменений. Мок транслирует изменения между экранами сразу. Supabase-реализация слушает каналы и обновляет те же потоки.

## ИИ

`AiService` — интерфейс:
- `Future<int> computeCompatibility(Profile a, Profile b)` — процент совместимости;
- `Future<List<String>> suggestTopics(Profile a, Profile b)` — темы для разговора;
- `Future<String> translate(String text, String targetLang)` — перевод.

Сейчас `MockAiService` возвращает детерминированные значения. Замена на реальный провайдер — без правок UI.

## Темы

`core/theme` содержит токены (`AppColors`, `AppSpacing`, `AppRadius`) и 5 неоновых тем (`AppTheme.violet()`, `.pink()`, `.green()`, `.sunset()`, `.ice()`). `ThemeController` (Riverpod) управляет выбором и сохраняет его в `shared_preferences`.
