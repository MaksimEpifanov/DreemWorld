## 1. Что такое Dreem World

**Dreem World** — кроссплатформенное приложение (Android / iOS / Web) на Flutter.
Актуальная реализованная концепция: **«галактика интересов»** — неоновый социальный
продукт, где интересы представлены планетами-сообществами. Пользователь исследует
планеты, входит во внутренний мир планеты, смотрит карту, новости, подбирает людей по
совместимости, общается в чатах. Есть темы оформления, безопасность/модерация,
внутриигровая валюта, подписка Dreem+.

Слоган раннего концепта: **«Connect. Understand. Belong.»**

### Аудитория и цель (требует уточнения в деталях)
- Позиционирование: знакомства и общение по интересам/совместимости с помощью ИИ.
- Точная целевая аудитория, монетизация и метрики успеха — **требует уточнения**.

### Навигация (go_router) — подтверждено кодом
- Публичные маршруты: `/login`, `/register`, `/onboarding`, `/splash`.
- `redirect` зависит от `authControllerProvider` и `hasSavedProfileProvider`.
- Оболочка `StatefulShellRoute.indexedStack` с 4 вкладками:
  `/main` (главная-планеты), `/discovery`, `/chats`, `/contacts`.
- Вложенные: `/main/planets`, `/main/other-interests`, `/main/planet/:id`,
  `/main/planet/:id/map`, `/main/planet/:id/news`.
- Полноэкранные: `/profile`, `/settings`, `/safety`, `/minigames`, `/chat/:id`, `/match`.

## 4. Ключевые текущие фичи (реализовано в коде)

- **Главная (PlanetHomeScreen)**: солнце в центре и планеты, профиль, уведомления, меню.
- **Каталог «Все планеты»**: орбитальный каталог (`OrbitalCatalog`) с 22 планетами-сообществами.
- **Планета-сообщество**: `Planet` + `PlanetScene` (24 сцены: fishing, travel, cinema, books,
  music, sports, reading, art, technology, food, nature, gaming, cars, animals, gardening,
  esoteric, finance, volunteering, psychology, other, selfDevelopment, collecting, space, …).
- **Карта внутреннего мира планеты**: отметки, теги, комментарии (`MapSpot`).
- **Лента новостей планеты** с ежечасным обновлением (`PlanetNews`).
- **Подбор (Discovery)** с процентом совместимости и статусом отношений.
- **Мэтч**, **чаты** (подвкладки Все / По интересам / Непрочитанные), заблокированный видеовызов.
- **Контакты по QR** (`qr_flutter`, мой код, мок-сканер).
- **Кошелёк**: валюта за входы + мини-игра «Колесо удачи».
- **Dreem+** — карточка подписки (демо, оплата не подключена).
- **Безопасность**: жалобы, ИИ-фильтр, блокировки, возрастной контроль, Центр безопасности.
- **Аутентификация**: реальная Firebase-аутентификация с безопасным откатом на мок-режим.
  Google/Phone в слое сервисов **не реализованы** (требует уточнения приоритета).
- **Темы**: неоновые темы оформления + глобальный космический фон с Млечным Путём.

### Проблема раскладки OrbitalCatalog (текущая задача)
- Экран «Все планеты» на **ПК**: планеты наслаивались, нижняя планета обрезалась.
- Решение (задеплоено): размеры планет/солнца считаются от **меньшей стороны** области
  (`min(w, h)`), орбиты растягиваются по ширине, размер планеты ограничен шагом по дуге,
  углы колец чередуются.
- **Экран телефона** для этой задачи **отложен** (делаем позже) — по решению пользователя.
- Остаточный статус: **на проверке пользователем** (нужен Ctrl+F5). Если проблема остаётся —
  смотреть заново геометрию и фактическую высоту области под заголовком.

## 6. Принятые решения и ограничения окружения

- **Язык интерфейса и кода — русский.**
- **Android SDK локально отсутствует** → APK только через GitHub Actions.
  iOS собирается только на macOS.
- Пуш иногда падает `Recv failure: Connection was reset` — ретраить.
- Модель (агент) **не читает изображения**; визуал — процедурный, с авто-подхватом PNG:
  `assets/planets/<id>.png` (×22) и `assets/space/sun.png` через `Image.asset` + `errorBuilder`.
  Реальные PNG от пользователя **пока не предоставлены** (папки ждут файлов).
- **Firebase** реально настроить нельзя без логина пользователя в Google (отложено).
- **`edit` к `orbital_catalog.dart` иногда откатывается** — писать файл целиком.
- **Не выполнять `git push` / публикацию без явного разрешения.**
- Синхронизация: пользователь работает с GPT на телефоне; GPT даёт **текстовые промты**;
  изменения в репозиторий вносит только локальный агент.

## 7. Восстановленные исторические материалы (архив, НЕ текущий код)

В репозитории лежат материалы восстановления более ранней истории проекта
(собраны 11.10.2026). Они описывают **две разные концепции** и частично устарели.

**Версия A — DREEMWORLD (социальный сервис, 17.08.2026).**
Социальный ИИ-чат для поиска людей по совместимости. Слоган «Connect. Understand. Belong.».
Функции: профиль (интересы/цели/ценности), анализ ИИ, подбор совместимых людей,
чат с мгновенным переводом, подсказки тем, глобальное сообщество, приватность,
обучение на обратной связи. Стек на борде: AI/ML, NLP, real-time translation,
шифрование, iOS/Android/Web. Файл: `assets/Неоновая концепция Dreemworld: мир общения.txt.png`.

**Версия B — Dream World (цифровое пространство-органайзер, 07.09.2026).**
Единое пространство для проектов, задач, документов, файлов, заметок и идей.
Материалы: презентации Lite и Visual (по 8 слайдов), Android-макеты (6 экранов:
«Ваше пространство», «Ремонт квартиры», «Все задачи», «Смета ремонта», «Проект: Ремонт квартиры»,
«Найти в Dream World»). Есть упоминание **Unified Data Model v1** (Project, Document, Task,
File, Note, Idea, Tag, Relation; права, версии, журнал событий, графовый поиск) — из сводки памяти,
не из полных чатов.

**Идея «Галактика возможностей» (17.08.2026).**
Макет «галактика интересов»: выбрать направление, исследовать сектора/планеты,
находить близких по интересам, общаться. Направления: активный образ жизни, общение и дружба,
путешествия, творчество/хобби, семейная жизнь, саморазвитие. Схема «Как это работает»:
выбрать направление на карте галактики → исследовать планету/сектор → смотреть профили →
общаться и делиться впечатлениями. **Именно эта идея лежит в основе текущей реализации.**

Папки архива: `01_Chronology`, `02_Project_Spec`, `03_Files_Inventory`,
`04_Conversation_Reconstruction`, `05_Extracted_Text`, `06_Limitations`, `assets/`, `README.txt`.

## 8. Идея галактики с движущимися планетами и исследованием сцены

Зафиксированная идея (для будущей реализации, **ещё не реализована**):

- **Галактика интересов с движущимися планетами**: планеты-сообщества не статичны,
  а движутся по орбитам/дрейфуют; сцена «живая».
- **Интерактивное исследование сцены**: пользователь может свободно исследовать
  космическую сцену — приближать/отдалять, перетаскивать, выбирать планету,
  «влетать» в её внутренний мир (карту, новости, сообщество).
- Планеты = интересы/направления (активный образ жизни, путешествия, творчество,
  дружба, семья, саморазвитие и др.).
- Возможная связь с функцией «Галактика возможностей» из архивного макета.

**Требует уточнения:** конкретная механика движения (орбиты/физика), объём интерактива,
нужен ли отдельный режим-«карта галактики» или интеграция в существующий `OrbitalCatalog`.

## 11. Противоречия и что требует уточнения

- **Две концепции** (социальный сервис «DREEMWORLD» vs органайзер «Dream World») — связь
  и намеренность перехода **не подтверждены**. Текущее приложение ближе к «галактике интересов» из версии A.
- **Supabase vs Firebase** — оба присутствуют; что из них целевой бэкенд — **уточнить**.
- **Монетизация** (подписка Dreem+, валюта) — детали и реальные платежи **не подтверждены**.
- **Полных дословных чатов** раннего проекта нет (только сводки и извлечённые тексты).
  Полный архив можно получить через экспорт данных аккаунта ChatGPT (`conversations.json`).
