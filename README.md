# Dreem World

**Dreem World** — кроссплатформенное приложение для знакомств, общения и поиска людей по всему миру по интересам, со встроенным искусственным интеллектом.

Слоган: **«Connect. Understand. Belong.»**

## Суть проекта

Людей подбирают не просто по фото, а по **совместимости**: ИИ анализирует интересы, ценности и стиль общения, находит подходящих людей и помогает в диалоге.

## Ключевые функции

- **ИИ-совместимость** — процент совпадения с другим пользователем
- **Умный подбор людей** — поиск по интересам, ценностям и совместимости
- **Чат с автопереводом** — общение без языкового барьера
- **Подсказки тем для разговора** — ИИ помогает завязать и поддерживать диалог
- **ИИ-помощник** — встроенный ассистент внутри приложения
- **Глобальное сообщество** — знакомства со всем миром
- **Профиль с интересами и ценностями** — детальная анкета пользователя
- **Приватность и безопасность** — настройки приватности, шифрование данных
- **Обучение на обратной связи** — система улучшается по мере использования

## Стек

| Область | Технология |
|---|---|
| Язык / фреймворк | **Flutter 3.47.7** · Dart 3.13.5 |
| Управление состоянием | **Riverpod** |
| Навигация | **go_router** |
| Бэкенд и реалтайм | **Supabase** (Postgres + Realtime + Auth + Storage) за абстракцией репозиториев |
| ИИ | Интерфейс `AiService` + мок-реализация |
| Автоперевод | Интерфейс `TranslationService` + мок-реализация |
| Локальное хранилище | `shared_preferences` + in-memory кэш |
| Дизайн | Неоновый вайб, 5 переключаемых тем (Material 3) |

## MVP: состав экранов

1. **Splash** — заставка + логотип
2. **Onboarding** — слайды с идеей приложения
3. **Создание профиля** — имя, возраст, город, интересы, цели, ценности
4. **Выбор темы** — 5 неоновых вариантов
5. **Подбор (Discovery)** — карточки людей с процентом совместимости
6. **Мэтч** — экран взаимной симпатии
7. **Чаты** — список диалогов
8. **Чат** — переписка + кнопка автоперевода + подсказки тем от ИИ
9. **Настройки** — выбор темы, приватность, выход

## Как запустить (приложение)

Код приложения находится в папке [`app/`](app/).

```powershell
cd app
flutter pub get
flutter run                    # выбрать устройство (Android/iOS/Web)
flutter analyze                # статический анализ
flutter test                   # тесты
flutter build web --release    # релизная сборка Web → build/web
```

Требуется установленный [Flutter](https://docs.flutter.dev/get-started/install) (стабильный канал).
