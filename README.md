# Dreem World

**Dreem World** — мобильное приложение (Android + iOS) для знакомств, общения и поиска людей по всему миру по интересам, со встроенным искусственным интеллектом.

Слоган: **«Connect. Understand. Belong.»**

## Суть проекта

Людей подбирают не просто по фото, а по **совместимости**: ИИ анализирует интересы, ценности и стиль общения, находит подходящих людей и помогает в диалоге.

## Ключевые функции

- **ИИ-совместимость** — процент совпадения с другим пользователем
- **Умный подбор людей** — поиск по интересам, ценностям и совместимости
- **Чат с автопереводом** — общение без языкового барьера
- **Подсказки тем для разговора** — ИИ помогает завязать и поддерживать диалог
- **ИИ-помощник** — встроенный ассистент внутри приложения
- **Глобальное сообщество** — знакомства со всем миром
- **Профиль с интересами и ценностями** — детальная анкета пользователя
- **Приватность и безопасность** — настройки приватности, шифрование данных
- **Обучение на обратной связи** — система улучшается по мере использования
- **Кроссплатформенность** — iOS, Android, Web

## Технологии (заявленные в концепте)

AI/ML, NLP, real-time translation, безопасность/шифрование, iOS / Android / Web.
